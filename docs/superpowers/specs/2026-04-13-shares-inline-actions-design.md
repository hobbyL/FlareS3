# 分享页链接列与操作列单行化设计

**目标**

在分享中心列表页中，将链接列调整为“链接文本 + 纯图标操作按钮”单行布局；将操作列调整为单行按钮布局，并将操作文案精简为双字，避免表格单元格内换行导致的高度抖动。

**范围**

- 修改 [`frontend/src/views/Shares.vue`](/Users/mhp/Documents/workspace/wj/github/flares3/frontend/src/views/Shares.vue) 的列渲染与样式。
- 修改分享页中英文文案，使操作列按钮文案收敛到更短版本。
- 为上述结构和样式补充源码级测试，防止后续回退。

**设计**

1. 链接列保持现有 tooltip 和截断展示逻辑，按钮改为仅图标。
2. 复制和打开按钮保留可访问名称，避免图标按钮失去语义。
3. `share-link-cell` 从纵向堆叠改为横向布局，链接文本占满剩余空间，按钮区域禁止换行。
4. 操作列延续现有按钮结构，但 `action-buttons` 禁止换行；一次性分享按钮文案改为“重置”，关闭分享按钮文案改为“禁用”。
5. 不引入新组件，不重构表格抽象，保持改动集中，遵循 KISS/YAGNI。

**影响与风险**

- 操作列宽度可能需要微调，以稳定容纳双字文案与图标。
- 图标按钮若缺少可访问标签会降低可用性，因此实现中必须补齐 `aria-label`。
- 由于当前采用源码级静态测试，需要保证断言对现有代码风格足够稳健，避免无意义脆弱匹配。
